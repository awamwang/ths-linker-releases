同花顺助手 ths-linker

Windows 本地联动工具：读取同花顺当前选中股票，经 WebSocket / HTTP 推送与跳转，并支持自选股与交易相关能力。 本站仅提供安装包与基础文档，不含源码。

下载 Releases 使用说明与接口 变更记录

快速开始

  • 启动同花顺官方最新版客户端
  • 运行 ths-linker.exe，在「监控」页勾选实例并点「启动」
  • 需要外部程序对接时，见文档中的 WebSocket / HTTP 章节

系统要求

Windows 10/11（x64）。精简系统若缺少运行库，请安装 Microsoft Visual C++ Redistributable（x64）。
